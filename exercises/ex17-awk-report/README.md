## 1. どんな場面で必要になるか

監視ツールを動かし続けると、手元には「いつ・どのサーバーが・OKだったかNGだったか」という記録が延々とたまっていきます。ex16 までで作ってきたのは「異常が起きた瞬間に気づく」仕組みでしたが、運用の現場ではもう1つ、**月末に「先月このサーバーは何%動いていたか」を報告する**という仕事があります。

「先月web02は99.9%稼働していました」と言えるかどうかは、契約上の約束(SLA: サービス品質保証)を守れたかの証拠になります。数万行のログを目視で数えるわけにはいかないので、集計はスクリプトにやらせます。

このとき主役になるのが `awk` (オーク) です。`awk` は「行を区切り文字で分解して、条件に合う行だけ数える・計算する」ことに特化した小さなプログラミング言語で、Linuxにはほぼ必ず入っています。案件No.4の `health_check.sh` にも `calc_uptime` という関数があり、そこで `awk` を使って稼働率を計算しています。この演習では、その集計部分を「複数ホストぶんまとめて表にする」ところまで自分の手で書きます。

## 2. この演習で学ぶこと

| 学ぶこと | ひとことで言うと |
|---|---|
| `awk` の基本形 | `awk 'パターン { 処理 }' ファイル` で、行ごとに処理を書ける |
| `-F','` | 区切り文字をカンマにする指定。`$1` `$2` `$3` で各列を取り出せる |
| 連想配列 | `total["web01"]++` のように、文字列をキーにして数を数える箱 |
| `END` ブロック | 全部の行を読み終えたあとに1回だけ動くブロック。集計結果はここで出す |
| `-v` | シェルの変数を `awk` の中へ渡す方法。`-v th="$THRESHOLD"` |
| `printf` の桁ぞろえ | `%-6s` は左寄せ6桁、`%5.1f` は右寄せ5桁の小数第1位 |

### 3分でわかる予備知識

**awk は「1行ずつ処理を繰り返す」道具**

`awk` は、渡されたファイルを**上から1行ずつ**読み、行ごとに `{ }` の中を実行します。`for` 文を書かなくても、勝手に全行を回してくれると考えてください。

```bash
awk '{ print $1 }' monitor.log      # 各行の1列目だけを表示する
```

**列は $1 $2 $3 で取り出す。区切り文字は -F で指定する**

既定の区切り文字は空白ですが、今回のログはカンマ区切りなので `-F','` を付けます。

```text
2026-09-01 09:00:00,web01,OK
└──────── $1 ────────┘ └$2┘ └$3┘
```

```bash
awk -F',' '{ print $2, $3 }' monitor.log    # → web01 OK
```

`$0` は「行全体」です。`$1` は日時、`$2` はホスト名、`$3` は結果になります。

**連想配列で数を数える**

`awk` の変数は宣言なしで使え、数値は0から始まります。`配列[文字列]` の形で「文字列をキーにした箱」が作れます。

```bash
awk -F',' '{ total[$2]++ }' monitor.log
```

この1行が動くと、内部では次のように箱が増えていきます。

```text
1行目 2026-09-01 09:00:00,web01,OK  →  total["web01"] が 1 になる
2行目 2026-09-01 09:05:00,web01,NG  →  total["web01"] が 2 になる
3行目 2026-09-01 09:00:00,web02,OK  →  total["web02"] が 1 になる
```

「OKの数」だけを別の箱で数えれば、稼働率が計算できます。

```bash
awk -F',' '{ total[$2]++; if ($3 == "OK") ok[$2]++ }' monitor.log
```

**END ブロックで結果を出す**

`{ }` の中は「行を読むたび」に実行されますが、`END { }` の中は**最後に1回だけ**実行されます。集計結果を出すのはここです。配列を全部なめるには `for (キー in 配列)` を使います。

```bash
awk -F',' '
    { total[$2]++ }
    END {
        for (host in total) {
            print host, total[host]
        }
    }
' monitor.log
```

注意点が1つあります。**`for (host in total)` の取り出し順はバラバラ**です(登録順でも辞書順でもありません)。並び順をそろえたいときは、出力を `sort` コマンドに通します。

```bash
awk ... monitor.log | sort
```

**シェルの変数を awk に渡す**

`awk` のプログラムはシングルクォートで囲むため、中に `$THRESHOLD` と書いてもシェルの変数は展開されません(そもそも `awk` の `$` は「列番号」の意味なので混ざると危険です)。`-v 名前=値` を使って明示的に渡します。

```bash
THRESHOLD=99
awk -v th="$THRESHOLD" 'BEGIN { print th }'      # → 99
```

**printf で桁をそろえる**

`echo` は文字をそのまま出すだけですが、`printf` は幅を指定できるので表になります。

```bash
printf '%-6s %5.1f%%\n' "web01" "100.0"     # → web01  100.0%
printf '%-6s %5.1f%%\n' "web02" "90.0"      # → web02   90.0%
```

- `%-6s` … 文字列を6桁ぶんの幅で**左寄せ**する(余りは右側が空白になる)
- `%5.1f` … 数値を5桁ぶんの幅で**右寄せ**し、小数第1位まで表示する
- `%%` … `%` そのものを出したいときの書き方(`%` は書式指定の記号なので2つ重ねる)
- `printf` は `echo` と違って改行を付けないので、末尾に `\n` を書く

## 3. 課題

`work/uptime_report.sh` を編集し、監視ログから**ホストごとの稼働率レポート**を作るスクリプトを完成させてください。

入力する監視ログは、1行1レコードのカンマ区切りです。

```text
2026-09-01 09:00:00,web01,OK
2026-09-01 09:05:00,web01,NG
```

- 1列目: 日時
- 2列目: ホスト名
- 3列目: 結果(`OK` または `NG`)

### 仕様

| No. | 条件 | 期待する動作 |
|---|---|---|
| 1 | `uptime_report.sh <監視ログファイル>` で実行 | 稼働率レポートを標準出力に表示する。しきい値は既定の `99` (%) |
| 2 | `uptime_report.sh <監視ログファイル> <しきい値>` で実行 | 第2引数をしきい値(%)として判定する |
| 3 | 引数なしで実行、または引数が3個以上 | 使い方を**標準エラー出力**に表示し、終了ステータス `1` で終わる |
| 4 | 指定したログファイルが存在しない | `見つかりません` を含むエラーを**標準エラー出力**に表示し、終了ステータス `1` で終わる |
| 5 | 集計 | ホスト名ごとに総件数とOK件数を数え、稼働率 = OK件数 ÷ 総件数 × 100 を小数第1位まで求める |
| 6 | 空行、および `#` で始まる行 | 集計対象から除外する |
| 7 | 並び順 | ホスト名の昇順(`sort` を通す)で1行ずつ表示する |
| 8 | 判定 | 稼働率がしきい値**未満**なら `要確認`、しきい値**以上**なら `正常` |
| 9 | 終了ステータス | しきい値未満のホストが1つでもあれば `1`、1つも無ければ `0` |

### 出力フォーマット

1行目は見出し、2行目以降がホストごとの明細、最後の1行がサマリです。

```text
ホスト名  OK/総数  稼働率  判定
web01  30/30  100.0%  判定: 正常
web02  27/30   90.0%  判定: 要確認
集計対象: 60件 / ホスト数: 2件 / しきい値: 99%
```

- 見出し行は `ホスト名  OK/総数  稼働率  判定`(区切りは半角スペース2つ)をそのまま表示する
- 明細行は `printf '%-6s %-6s %5.1f%%  判定: %s\n' "<ホスト名>" "<OK件数>/<総件数>" "<稼働率>" "<判定>"` で出力する
  - ホスト名: 左寄せ6桁
  - `OK件数/総件数`: 左寄せ6桁(スラッシュは半角)
  - 稼働率: 右寄せ5桁の小数第1位、直後に半角 `%`
  - そのあと半角スペース2つ + `判定: ` + `正常` または `要確認`
- サマリ行は `集計対象: <総レコード数>件 / ホスト数: <ホスト数>件 / しきい値: <しきい値>%` の形式
  (区切りは ` / ` = 半角スペース+スラッシュ+半角スペース)

### 実行例

次の `monitor.log` を用意したとします。

```text
# 2026-09-01 の監視ログ
# 2026-09-01 10:00:00,web99,NG
2026-09-01 09:00:00,web01,OK
2026-09-01 09:05:00,web01,OK
2026-09-01 09:00:00,web02,OK
2026-09-01 09:05:00,web02,NG

2026-09-01 09:10:00,web02,OK
```

しきい値を省略した場合(既定 `99`)は、次のように表示されます。

```text
$ bash uptime_report.sh monitor.log
ホスト名  OK/総数  稼働率  判定
web01  2/2    100.0%  判定: 正常
web02  2/3     66.7%  判定: 要確認
集計対象: 5件 / ホスト数: 2件 / しきい値: 99%
$ echo $?
1
```

- 先頭2行はコメント行なので集計されません。`web99` は表に現れません
- 空行も集計されません。`集計対象` は5件です
- `web02` が99%未満なので、終了ステータスは `1` になります

しきい値を `60` にすると、両方とも `正常` になり、終了ステータスは `0` になります。

```text
$ bash uptime_report.sh monitor.log 60
ホスト名  OK/総数  稼働率  判定
web01  2/2    100.0%  判定: 正常
web02  2/3     66.7%  判定: 正常
集計対象: 5件 / ホスト数: 2件 / しきい値: 60%
$ echo $?
0
```

## 5. ヒント

<details>
<summary>ヒント1: 処理を3つに分けて考える</summary>

いきなり全部を1つの `awk` で書こうとすると難しくなります。次の3段階に分けてください。

1. **集計する**: `awk` でログを読み、ホストごとに「OK件数」「総件数」「稼働率」「判定」を計算し、**1ホスト1行**の中間データを作る
2. **並べる**: `awk` の出力を `sort` に通してホスト名の昇順にする
3. **整形する**: シェル側で1行ずつ読み直し、`printf` で表の形に整える。同時に総レコード数・ホスト数・しきい値未満の件数を数える

中間データは、あとで `read` で分解しやすいように**半角スペース区切り**にしておくと扱いやすいです。

```text
web01 30 30 100.0 正常
web02 27 30 90.0 要確認
```

</details>

<details>
<summary>ヒント2: awk と while read の書き方</summary>

集計する `awk` は次の形になります。`next` は「この行の処理をここで打ち切って次の行へ進む」という命令です。

```bash
awk -F',' -v th="$THRESHOLD" '
    /^[[:space:]]*$/ { next }      # 空行は集計しない
    /^[[:space:]]*#/ { next }      # コメント行は集計しない
    {
        total[$2]++
        if ($3 == "OK") { ok[$2]++ }
    }
    END {
        for (host in total) {
            rate = (ok[host] + 0) / total[host] * 100
            # 三項演算子: 条件 ? 真のとき : 偽のとき
            judge = (rate < th) ? "要確認" : "正常"
            printf "%s %d %d %.1f %s\n", host, ok[host] + 0, total[host], rate, judge
        }
    }
' "$LOG_FILE"
```

`ok[host] + 0` としているのは、1件もOKが無いホストで `ok[host]` が空文字のままだからです。`+ 0` を付けると数値の `0` として扱えます。

シェル側で1行ずつ読むには `while read` を使います。変数に入れた複数行の文字列を読ませるには `<<<` (ヒアストリング) が便利です。

```bash
while read -r host ok total rate judge; do
    [[ -z "$host" ]] && continue      # 空行は飛ばす
    printf '%-6s %-6s %5.1f%%  判定: %s\n' "$host" "${ok}/${total}" "$rate" "$judge"
done <<< "$STATS"
```

</details>

<details>
<summary>ヒント3: 全体の骨組み</summary>

```bash
#!/bin/bash
set -u

usage() {
    echo "使い方: $(basename "$0") <監視ログファイル> [<しきい値(%)>]"
}

# 引数の個数チェック(1個または2個以外はエラー)
if [[ "$#" -lt 1 || "$#" -gt 2 ]]; then

fi

fi

# 2. 見出し行

    ...
```

## 6. よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| `awk: line 1: syntax error at or near ]` のような syntax error が出る | `awk` のプログラムをダブルクォートで囲んでいる。シェルが先に `$2` を展開してしまい、`total[]++` という壊れたプログラムが `awk` に渡っている。シングルクォート `'...'` で囲む(文言は awk の種類によって少し変わる) |
| しきい値を変えても判定が変わらない / 判定がでたらめになる | `awk` の中でシェル変数を `$THRESHOLD` のように直接書いている。`awk` の `$` は「列番号」の意味なので、`$THRESHOLD` は「THRESHOLD 列目」と解釈されてしまう。`-v th="$THRESHOLD"` で渡し、中では `th` と書く |
| 表に空欄のホストや `#` 始まりの行が混ざる | 空行・コメント行を `next` で除外していない。`$2` が空のまま `total[$2]++` すると「名前が空のホスト」ができる |
| ホストの並び順が毎回変わる | `for (host in total)` の順番は不定。`awk ... \| sort` のように `sort` に通す |
| `syntax error: invalid arithmetic operator` と出る | 稼働率(小数)を `$(( ))` で計算しようとしている。bashの算術演算は整数のみ。小数の計算は `awk` に任せる |
| 桁がそろわない | `echo` で出力している。`printf '%-6s %-6s %5.1f%%  判定: %s\n' ...` を使う |

`./check.sh 17` が失敗したときは、**「期待」と「実際」の差分**を1文字ずつ見比べてください。空白の数が1つ違うだけでも不一致になります。
