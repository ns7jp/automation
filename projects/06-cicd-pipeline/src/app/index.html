GitHub Actions CI/CD自動デプロイパイプライン 検証用サイト

このページについて

このページは、GitHub Actionsによる自動デプロイパイプラインの 動作確認用に用意したサンプルWebアプリです。mainブランチへ pushすると、自動テスト(shellcheck・簡易テスト)を経て、このページの 内容が自動的に検証/本番サーバーへ反映される仕組みになっています。

デプロイ状況の確認方法

直近のデプロイ情報は deploy-info.txt から確認できます。このファイルはデプロイのたびに scripts/deploy.shが自動生成・上書きするため、 「いつ・どのコミットが反映されたか」を後から追跡できます。
