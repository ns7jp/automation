# 案件No.2: 定期バックアップ自動化&世代管理ツール

## 難易度

★★☆☆☆(初級)

cron(=Linuxで「決まった時刻に処理を自動実行する」ための仕組み)とシェルスクリプトの基礎が中心。案件No.1(ユーザーアカウント自動化)よりも扱う技術要素は少ないが、「なぜそのオプションを使うのか」を理解しながら組み立てる必要があるため、単純な写経では終わらない難易度に設定している。

## 想定依頼元・背景

株式会社サンプル商事(架空の企業)。同社が運用するWebサーバーのコンテンツを担当者が手動でバックアップしていたが、ある日バックアップを取り忘れてデータ消失の危機があった。

このヒヤリハットを受けて、「人の手に頼らず、毎日自動でバックアップを取り、かつ古いバックアップは自動で整理される仕組みを作ってほしい」という依頼が来た、という想定でこの案件は設計されている。

## 依頼内容(要求仕様)

- 指定した対象ディレクトリ(例: `/var/www/html`)を日次で `tar.gz` 形式に圧縮し、バックアップ用ディレクトリに保存する
- バックアップファイル名に日付(`YYYYMMDD`)を含める
- 7世代(7日分)を超えた古いバックアップは自動的に削除する(`find` コマンドの日数指定を活用)
- `cron` で毎日AM3:00に自動実行されるようにする
- バックアップの成功/失敗をログファイルに記録し、失敗時には管理者へ通知する(今回は `curl` によるSlack Webhook通知(=あらかじめ発行されたURLへHTTPでデータを送るだけでSlackにメッセージを投稿できる仕組み)を採用)
- (発展要件)バックアップ先の空き容量が閾値(例: 80%)を超えそうな場合は警告を出す

詳細は [01-requirements.md](./01-requirements.md) を参照。

## 使用技術・ツール

- **OS**: Ubuntu Server 22.04 LTS
- **Bash**: シェルスクリプトによる処理の実装
- **tar / gzip**: ディレクトリの圧縮バックアップ
- **find**: 更新日時を基準にした古いファイルの検索・削除(世代管理)
- **cron**: 定期実行の仕組み(`crontab -e`)
- **df**: バックアップ先の空き容量チェック
- **curl**: Slack Incoming Webhookへの通知送信
- **date**: 日付フォーマットの生成
- **logrotate**: ログファイルの自動ローテーション(運用強化)

## この案件で身につくスキル

- cronの書式(分・時・日・月・曜日)を理解し、任意のタイミングで処理を自動実行できる
- `tar` / `find` / `df` といった実務で頻出するLinuxコマンドを、オプションの意味まで含めて使いこなせる
- 「フルバックアップ」「世代管理」「RPO」といったバックアップ設計の基本用語を理解し、説明できる
- スクリプトの異常終了を検知し、ログ記録と外部通知(Slack)につなげる「運用を止めない」設計ができる
- 設定(config)とロジック(script)を分離する、保守性を意識したスクリプト設計ができる

## 面接でアピールできるポイント(3つ、実際に話すセリフ例つき)

1. **cronとfindを組み合わせた自動化・世代管理の実装力**
   > 「毎日AM3時にcronでバックアップスクリプトを自動実行し、`find -mtime +7` で7日より古いバックアップだけを自動削除する仕組みを作りました。単に消すだけでなく、`-mtime` が『24時間単位の切り捨てで日数を判定する』という挙動まで理解した上で、意図通りに世代が管理されることをテストで確認しています。」

2. **障害を『検知して終わり』にせず、通知まで自動化した運用視点**
   > 「バックアップが失敗しても誰も気づかなければ意味がないと考え、失敗時にSlackへ自動通知する仕組みを組み込みました。また発展要件として、バックアップ先の空き容量が80%を超えたら事前に警告を出すようにし、『壊れてから気づく』のではなく『壊れる前に気づける』設計を意識しました。」

3. **設定とロジックを分離した、保守しやすいスクリプト設計**
   > 「対象ディレクトリや保存世代数などをスクリプト本体に直書きせず、`backup.conf` という設定ファイルに切り出しました。これにより、運用担当者がスクリプトのロジックを触らずに設定変更だけで対応でき、Webhook URLなどの秘匿情報もファイルの権限(`chmod 600`)で保護する、という実務を意識した作りにしています。」
